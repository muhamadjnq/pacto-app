# Pacto — اپ اندروید (نسخه‌ی ۲)

اپ مشتریان پکتو: سفارش تبلیغ، پیگیری سفارش، داشبورد زنده‌ی نتایج، کیف پول، پشتیبانی و ابزارهای رشد

## ساخت فایل نصب (APK) بدون نصب هیچ برنامه‌ای

۱. در گیت‌هاب وارد تب **Actions** شوید
۲. برای نسخه‌ی آزمایشی: «۳) ساخت APK آزمایشی» با هر تغییر روی شاخه‌ی `v2` خودکار ساخته می‌شود؛ فایل را از پایین همان صفحه (Artifacts) بردارید
۳. برای نسخه‌ی انتشار: «۲) ساخت APK نهایی» ← **Run workflow** ← شاخه‌ی `v2` را انتخاب کنید
   همان ۴ Secret قبلی (KEYSTORE_BASE64، KEYSTORE_PASSWORD، KEY_ALIAS، KEY_PASSWORD) استفاده می‌شود؛ پس اپ جدید روی نسخه‌ی قبلی به‌روزرسانی می‌شود

> «۱) ساخت کلید امضا» را دوباره اجرا نکنید؛ کلید جدید یعنی اپ دیگر روی نسخه‌ی قبلی نصب نمی‌شود

## پیش‌نیاز سمت سایت

اپ با نشانی `https://adpacto.com/api/v2` کار می‌کند. فایل‌های API نسخه‌ی ۲ باید روی سایت باشند (بسته‌ی `pacto-app-api.zip`)

تنظیم‌های اختیاری در جدول تنظیمات سایت:

| کلید | کاربرد |
|---|---|
| `app.android.min_version` | نسخه‌های قدیمی‌تر از این باید به‌روز شوند |
| `app.android.latest_version` | نمایش دکمه‌ی به‌روزرسانی در تنظیمات اپ |
| `app.android.update_url` | نشانی دریافت نسخه‌ی جدید (باید https باشد) |
| `app.android.notice` | متن صفحه‌ی به‌روزرسانی اجباری |

## ساختار پروژه

- `src/pages` — صفحه‌ها (هر صفحه یک فایل)
- `src/ui/kit.tsx` — اجزای مشترک ظاهر (دکمه، کارت، آیکون، برگه‌ی پایین و …)
- `src/lib` — ارتباط با سایت (`api.ts`)، کش داده (`query.ts`)، حساب و سبد (`store.ts`)، قفل اپ (`lock.ts`)، امکانات گوشی (`native.ts`)
- `assets` — آیکون و صفحه‌ی شروع
- `harden-android.cjs` — ایمن‌سازی پروژه‌ی اندروید هنگام ساخت
- `.github/workflows` — ساخت خودکار APK

## اجرا روی کامپیوتر (برای توسعه‌دهنده)

```
npm ci
npm run dev        # پیش‌نمایش در مرورگر
npm run build      # بررسی کد + ساخت
```

برای وصل شدن به سایت آزمایشی: `PACTO_API_BASE=https://example.com/api npm run build`

## تغییر شماره‌ی نسخه

فقط `version` در `package.json` را عوض کنید؛ شماره‌ی نسخه‌ی اندروید خودکار از همان ساخته می‌شود
